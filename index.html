Kiến thức cần nhớ trước khi làm

1. So sánh bằng

as + adjective/adverb + as
  • Tom is as tall as Nam.
  • She runs as fast as her brother.

2. So sánh không bằng

not as/so + adjective/adverb + as
  • Fansipan is not as high as Everest.
  • Walking is not as fast as cycling.

3. So sánh hơn

adj-er + than / more + adj + than
  • Health is more important than money.
  • Today’s exam is shorter than yesterday’s.

4. different from

A + be + different from + B
  • This house is different from my old house.

5. the same as

A + be + the same as + B
  • This piano is the same as that one.
  • the same size/height/width/depth as...

6. Từ chỉ kích thước

tall → height • wide → width

deep → depth • big → size • heavy → weight • long → length
  • John is the same weight as his sister.
